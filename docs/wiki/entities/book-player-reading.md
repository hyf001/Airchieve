# 绘本内容、播放器与阅读状态 (book-player / book / reading)

## 概述

管理绘本作为可播放内容资产（页面结构、双语文本、对白、对口型数据、共读提示、学习卡片）和用户级阅读状态（进度、收藏、历史、播放事件）。播放器消费服务端组装的 `BookPlayerPayload`。

## 前端归属

- `features/book-player`：播放、暂停、翻页、进度条、语言切换、语速、音效、声音切换、共读提示、学习卡片、试看裁剪、举报入口
- `features/reading`：继续阅读、收藏、阅读进度、播放事件上报
- `entities/book`：播放器页面结构、学习卡片、共读提示展示组件

## 后端归属

- `book`：绘本详情、页��、媒体、双语文本、音频、对白、共读提示、学习卡片、播放器 payload
- `reading`：收藏、阅读进度、阅读历史、播放事件
- `moderation`：举报入口

## 核心数据模型

| 模型 | 说明 |
| --- | --- |
| `books` | 绘本基础信息 |
| `book_pages` | 绘本页面 |
| `book_dialogues` | 对白 |
| `book_reading_prompts` | 共读提示 |
| `book_learning_cards` | 学习卡片 |
| `reading_progress` | 阅读进度 |
| `reading_favorites` | 收藏 |
| `reading_events` | 播放事件 |

## 播放片段与媒体轨道

播放器按页播放时，页面内容拆分为旁白/讲述片段和角色对白片段。两类片段共享整本绘本级背景音乐轨道，背景音乐从开始播放到结束播放连续混音；翻页时不得重新从头播放背景音乐。用户关闭背景音乐时只静音背景音乐，不影响朗读、对白或对口型播放。

- 旁白/讲述片段：使用当前页静态图片 `image_url`、页面朗读音频 `audio_url` 和背景音乐。讲故事的人说话时不需要生成角色对口型素材，画面保持为页面图片，可同步展示文字高亮。
- 角色对白片段：优先使用该角色对白的对口型视频/动画 `lip_sync_url`。对口型素材必须是“画面 + 声音”的完整可播放媒体；当片段 `media_mode=lip_sync` 时，播放器只播放 `lip_sync_url`，不得再叠加播放 `audio_url`，避免声音重复。没有对口型素材时，片段 `media_mode=audio`，播放器播放对白音频 `audio_url` 并展示页面图片。
- 字幕轨道：旁白/讲述片段和角色对白片段都必须在播放器字幕区展示对应文本。字幕内容随文本展示模式切换，中文模式显示中文，英文模式显示英文，中英双语模式同时显示中英文；角色对白字幕应能展示说话角色，便于儿童区分是谁在说话。字幕 cue 必须支持位置配置，例如底部、顶部、居中或自定义坐标，避免遮挡角色口型、关键画面或互动控件。
- 媒体引用规则：绘本播放层只保存可播放 URL；图片、页面音频、对白音频和对口型结果在绘本内容中不保存 asset id。生成或存储模块可以拥有中间 asset 记录，但进入 `book_pages` / `book_playback_segments` / `book_subtitle_cues` 后以 URL 作为播放器契约。
- 播放顺序：页面时间轴应能表达旁白片段与多个角色对白片段任意穿插，例如旁白 -> 对话 -> 对话 -> 旁白 -> 对话 -> 旁白。没有角色对白时，页面可以只播放图片 + 页面朗读音频 + 背景音乐；没有页面朗读音频但有对白时，按对白片段播放。
- 音效轨道：音效是独立 cue，可以挂在页面或具体播放片段上；同一页或同一片段可配置多个音效，每个音效有 URL、开始时间、结束时间、音量、是否循环和排序。

## 连续播放体验

播放器不应把旁白图片、角色对口型视频和对白音频表现成割裂素材列表，而应把每一页渲染成一个连续场景。前端以页面时间轴作为主控，把旁白片段和角色对白片段串成一个统一播放序列。

- 统一舞台：同一页播放期间保持固定画布、字幕区和控制栏，片段切换时不重排布局、不闪白、不显示加载态；旁白片段显示页面图片，角色对白片段切换到对应对口型视频/动画。
- 单一主时钟：页面播放由一个 timeline clock 驱动，控制播放、暂停、拖动、倍速和切页。图片、页面朗读音频、对白音频、对口型视频、字幕、音效和整本背景音乐都跟随这个主时钟。
- 预加载：当前片段开始后立即预加载下一片段的对口型视频、对白音频和字幕 cue；进入下一页前预加载下一页首个片段，避免片段交界处等待。
- 过渡策略：旁白转对白、对白转旁白时使用短过渡，例如 150-300ms 淡入淡出或保持上一帧到下一素材 ready；背景音乐不断轨，只做音量 ducking，避免听感断裂。
- 视觉连续性：角色对白结束后回到页面图片时，应回到同一页视觉上下文；如果对口型视频只覆盖角色区域，页面背景应保持一致。如果对口型视频是整页视频，结束帧应自然回落到页面图片。
- 音频混音：背景音乐是独立轨道，语音播放时自动压低背景音乐音量，语音结束后平滑恢复。旁白音频和对白音频同一时间只播放一个，避免儿童听感混乱。
- 容错降级：如果某段对口型视频未生成或加载失败，角色对白片段降级为页面图片 + 对白音频 + 字幕 + 背景音乐，但仍保留该片段在时间轴中的位置。

## 字幕同步

字幕不直接依赖渲染帧数，而依赖播放时间轴上的字幕 cue。每个旁白片段和角色对白片段都应生成可同步的字幕 cue，cue 时间以片段内相对时间为准，播放器再换算成页面或整本进度。

- 字幕 cue：每条 cue 至少包含 `segment_id`、`start_ms`、`end_ms`、`text_zh`、`text_en`、`speaker_ref` 和 `cue_type`。`cue_type` 区分旁白、角色对白、互动提示等字幕来源。
- 时间来源：优先使用 TTS/ASR 返回的字词级或句子级时间戳；如果供应商只返回整段音频，则按句子、标点和字数估算 cue 时间，并以实际音频时长做归一化。
- 主从关系：旁白字幕跟随页面朗读音频的 `currentTime`；角色对白字幕跟随对白音频/对口型视频所在片段的 `currentTime`。当音频和视频同时存在时，以音频作为听感主源，视频需要向音频时间对齐。
- 漂移修正：播放中持续检测音频、视频和 timeline clock 的差值。轻微漂移通过调整视频播放位置或播放速率修正；超过阈值时执行 seek 对齐，保证口型、声音和字幕不长期错位。
- 倍速与拖动：字幕 cue 使用媒体时间而不是墙钟时间，因此朗读速度变化、暂停、拖动进度和切页后，字幕应按当前媒体时间重新计算 active cue。
- 多语言显示：中文模式显示 `text_zh`，英文模式显示 `text_en`，中英双语模式显示同一 cue 的中英文。双语字幕共享同一时间窗口，不为中英文分别生成互相漂移的时间轴。
- 角色标识：角色对白字幕应显示 `speaker_ref` 对应的角色名称或短标签；旁白字幕不显示角色名，或显示统一的讲述者标签。
- 高亮粒度：MVP 可以做到句子级字幕同步；如果 TTS 返回字词级时间戳，再升级到逐词或短语高亮。

## 核心接口

- 绘本：`books`、`books/{id}`、`books/{id}/player`
- 阅读：`reading/recent`、`reading/favorites`、`reading/progress`、`reading/events`

## 复用入口

- 前端：`BookPlayer`、`ReadonlyBookPlayer`、`VoiceSwitcher`、`FavoriteButton`
- 后端：`get_book_detail()`、`get_player_payload()`、`save_reading_progress()`、`toggle_favorite()`

## 边界

- `book_player_service` 是 `book` 内部服务，不是独立模块
- `reading` 不修改绘本正文、页面、音频和媒体
- 儿童播放主流程不展示商业购买入口
